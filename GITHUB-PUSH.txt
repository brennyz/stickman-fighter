STICKMAN FIGHTER — PULL NAAR DEZE PC
====================================

GitHub main is LIVE (v1.18.151 / SW 361). Jij hoeft niet te pushen.
Op de pc alleen ophalen:

  cd stickman-fighter
  ./scripts/pull-main.sh

Eerste keer (als je het script nog niet hebt):

  git checkout main
  git pull origin main

Daarna opnieuw ./scripts/pull-main.sh — die stasht rommel, stapt
van een feature-branch af, en fast-forward (of reset) naar GitHub.

Klaar als:  git log -1 --oneline
toont een commit op main met v1.18.151 (of nieuwer).

GitHub Desktop: branch **main** kiezen → Fetch origin → Pull origin.

─── NA PULL ───

  Wacht ~1–3 min (Actions → Deploy GitHub Pages).
  Deel / spelen: https://brennyz.github.io/stickman-fighter/speel.html
  Oude cache: in het menu «Verse versie».

─── ALLEEN ALS JIJ NAAR GITHUB MOET PUSHEN ───

  git checkout main
  ./scripts/merge-push-main.sh
