# Forest floor photo samples

Drop close-up JPG/PNG shots of leaf litter / twigs / ivy here, then:

```bash
npm i -D sharp   # once
node scripts/sample-forest-floor.mjs
```

Paste the printed patch strings into `src/render/forest-floor.js` → `FOREST_FLOOR_PATCH_STRS`.

The game already ships hand-sampled patches from the three bosbodem photos used in production.
