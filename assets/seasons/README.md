# Season art slots

Pixel-art partner drops optional PNGs here. CSS overlays work without them.

See **`docs/SEASON-ASSET-SLOTS.md`** for sizes, safe zones, and tokens.

```
assets/seasons/
  classic/      (overlay hidden — optional empty)
  jungle/
  halloween/
  winter/       (hook)
  summer/       (hook)
```

Per season, these filenames are the contract:

- `corner-tl.png`
- `corner-tr.png`
- `corner-bl.png`
- `corner-br.png`
- `banner.png`
- `vignette.png`
- `ground-trim.png`
- `motif.png`

Preview: `index.html?season=halloween`
