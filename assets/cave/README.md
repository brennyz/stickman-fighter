# Cave photo → pixel scenery

Foto-refs (grot · water · amberrots · stalactieten) worden **niet** als raw image getoond.
Kleuren + silhouetten zijn hand-gemapt naar stickfight grit in:

- `src/render/cave-scenery.js` — floor tiles, waterband, stalactiet-gordijn, menu-vista
- `src/render/scenery.js` — `grot` far-tile + weer
- `src/render/backgrounds.js` — thema `grot` fight-BG

Later raw JPG/PNG hier droppen + `node scripts/sample-cave-floor.mjs` (optioneel) om patches te verversen.
